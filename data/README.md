# Data Directory (`data/`)

This directory houses the input datasets and summary covariance structures required to execute and verify the Cam-CAN Watershed Structural Equation Modeling (SEM) pipeline.

---

## Data Access & Ethics

Subject-level behavioural and neuroimaging data were obtained from **Stage 2** of the **Cambridge Centre for Ageing and Neuroscience (Cam-CAN)** repository ([https://www.cam-can.com](https://www.cam-can.com)). Cam-CAN received ethical approval from the Cambridgeshire 2 Research Ethics Committee (reference: `10/H0308/50`), and all participants provided written informed consent. Due to Cam-CAN data usage agreements, raw subject-level tables cannot be redistributed publicly and must be requested directly via the Cam-CAN portal.

However, **complete $20 \times 20$ manifest covariance matrices and mean vectors** for all four diffusion modalities ($N = 513$) are generated by the pipeline (`covariance_matrix_A.csv` through `covariance_matrix_D.csv` and `means_A.csv` through `means_D.csv` in `results/tables/`), enabling exact reproduction of the SEM covariance structures for Models A–D.

---

## Cohort Derivation Summary (CONSORT Flow)

1. **Initial Cam-CAN Stage 2 Intake:** $N = 653$ participants with demographic and structural MRI records.
2. **Sequential Cross-Modality Inner Merge:** $N = 550$ participants with complete records across demographics, Cattell Culture Fair subtests ($N = 634$), Simple RT ($N = 588$), Choice RT ($N = 577$), fMRI Audio-Visual RT ($N = 564$), JHU ICBM-DTI-81 diffusion parcellations ($N = 550$), and FreeSurfer `aseg`/`eTIV` morphometry ($N = 550$).
3. **Behavioural Quality Control Screening:** $N = 547$ valid participants retained after requiring `rt_simple_Include_participant == 1`, `rt_choice_Include_participant == 1`, and `mri_behav_include_participant == 1` ($3$ excluded; $99.45\%$ retained).
4. **Outlier Screening & Multi-Compartment Convergence Audit:**
   - Univariate outlier screening ($|z| > 4.0$ across manifest indicators) flagged $25$ unique participants ($4$ behavioural, $22$ white matter, $1$ overlap).
   - Non-linear multi-compartment diffusion optimization boundary checks flagged $9$ participants with incomplete/non-convergent FWE/WMTI fits.
   - Excluded participants ($n = 34$, mean age $70.55\text{ years}$) were significantly older than retained participants ($M = 53.75\text{ years}$, Wilcoxon $W = 4134$, $p = 1.19 \times 10^{-7}$).
5. **Final Harmonized Complete-Case SEM Cohort:** **$N = 513$ participants** ($253$ females, $260$ males; age range $18.6\text{--}88.0\text{ years}$, mean $53.75 \pm 17.95\text{ years}$).

## Expected Schema for `camcan_watershed_dataset.csv`

To run `R/watershed_sem_pipeline.R` from scratch on subject-level data, the input file `camcan_watershed_dataset.csv` must contain the following columns:

### 1. Demographics, QC Flags & FreeSurfer Morphometry

| Column Name                           | Description                                                            |
| :------------------------------------ | :--------------------------------------------------------------------- |
| `id`                                  | Unique Cam-CAN participant identifier                                  |
| `age`                                 | Chronological age in years                                             |
| `sex`                                 | Biological sex (`F` / `M`)                                             |
| `rt_simple_Include_participant`       | Behavioural QC inclusion flag for Simple RT (`1` = include)            |
| `rt_choice_Include_participant`       | Behavioural QC inclusion flag for Choice RT (`1` = include)            |
| `mri_behav_include_participant`       | Behavioural QC inclusion flag for fMRI Audio-Visual RT (`1` = include) |
| `aseg_Left_Lateral_Ventricle_volume`  | FreeSurfer `aseg` left lateral ventricle volume ($\text{mm}^3$)        |
| `aseg_Right_Lateral_Ventricle_volume` | FreeSurfer `aseg` right lateral ventricle volume ($\text{mm}^3$)       |
| `eTIV`                                | FreeSurfer estimated total intracranial volume ($\text{mm}^3$)         |

### 2. Fluid Intelligence & Reaction Time Paradigms

| Raw Column(s)                          | Engineered Variable | Transformation Formula                                                        |
| :------------------------------------- | :------------------ | :---------------------------------------------------------------------------- |
| `cattell_SubScore1`                    | `C1`                | $Z(\text{Series Completion})$                                                 |
| `cattell_SubScore2`                    | `C2`                | $Z(\text{Classification})$                                                    |
| `cattell_SubScore3`                    | `C3`                | $Z(\text{Matrices})$                                                          |
| `cattell_SubScore4`                    | `C4`                | $Z(\text{Conditions / Topology})$                                             |
| `rt_simple_RTmean` (s)                 | `SRTspeed`          | $Z(\ln(1 / \text{Mean RT}))$                                                  |
| `rt_simple_RTsd` (s)                   | `SRTcons`           | $Z(\ln(1 / \text{SD RT}))$                                                    |
| `rt_choice_RTmean_all` (s)             | `CRTspeed`          | $Z(\ln(1 / \text{Mean RT}))$                                                  |
| `rt_choice_RTsd_all` (s)               | `CRTcons`           | $Z(\ln(1 / \text{SD RT}))$                                                    |
| `mri_behav_mRT` (ms $\rightarrow$ s)   | `AVspeed`           | $Z(\ln(1 / \text{Mean RT}_{\text{sec}}))$ _(values $>10$ divided by $1,000$)_ |
| `mri_behav_stdRT` (ms $\rightarrow$ s) | `AVcons`            | $Z(\ln(1 / \text{SD RT}_{\text{sec}}))$ _(values $>10$ divided by $1,000$)_   |

### 3. JHU ICBM-DTI-81 White Matter Parcellations

For each of the 4 diffusion modalities, the raw dataset contains JHU atlas ROI columns prefixed by:

- `jhu_dti_fa_` $\rightarrow$ aggregated into `DTI_FA_<Tract>` (**Model A**: Conventional $\text{FA}$)
- `jhu_fwe_fa_` $\rightarrow$ aggregated into `FWE_FAtissue_<Tract>` (**Model B**: Free-Water-Eliminated $\text{FA}_{\text{tissue}}$)
- `jhu_wmti_awf_` $\rightarrow$ aggregated into `WMTI_AWF_<Tract>` (**Model C**: WMTI Axonal Water Fraction $\text{AWF}$)
- `jhu_fwe_frac_` $\rightarrow$ aggregated into `FWE_FW_<Tract>` (**Model D**: Isotropic Free-Water Fraction $\text{FW}$)
