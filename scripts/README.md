# Visualization Scripts (`scripts/`)

This directory contains `generate_publication_figures.py`, the automated Python visualization workflow that generates all 12 standalone vector publication figures (`.pdf` and `.svg`) directly from the CSV outputs of `R/watershed_sem_pipeline.R`.

---

## Usage

```bash
# Default execution (auto-detects CSVs in 'output/' or '.' and saves to 'output_figures/')
python3 scripts/generate_publication_figures.py

# Custom input and output directories matching repository layout
python3 scripts/generate_publication_figures.py \
  --data_dir results/tables \
  --output_dir results/figures
```

### Command-Line Arguments

- `--data_dir`: Directory containing the 13 required CSV output files generated by `watershed_sem_pipeline.R` (default: `"output"`, with automatic fallback to `"."`).
- `--output_dir`: Target directory where `.pdf` and `.svg` vector figures will be saved (default: `"output_figures"`).

---

## Required Input CSVs

Before generating figures, `generate_publication_figures.py` verifies the presence of 13 CSV tables in `--data_dir`:

1. `watershed_model_comparison.csv`
2. `directionality_model_comparison.csv`
3. `standardized_solutions_all_models.csv`
4. `tract_to_speed_paths_unadjusted.csv`
5. `wald_ATR_vs_FMin_unadjusted.csv`
6. `bootstrap_ATR_FMin_contrasts.csv`
7. `rsquared_unadjusted.csv`
8. `rsquared_adjusted.csv`
9. `preprocessing_summary.csv`
10. `cfa_fi_fit.csv`
11. `cohort_demographics.csv`
12. `cohort_sex_counts.csv`
13. `excluded_vs_retained_age.csv`
