## Complete Inventory of All 38 CSV Files in `results/tables/`

1. `age_correlations.csv` — Pearson ($r_{\text{age}}$) and Spearman ($\rho_{\text{age}}$) lifespan correlations for all behavioral and tract indicators ($N = 513$).
2. `bootstrap_ATR_FMin_contrasts.csv` — Empirical point estimates, bootstrap SEs, and marginal $95\%$ percentile CIs ($2.5\text{th}–97.5\text{th}$) across $B = 5{,}000$ converged parallel bootstrap draws for all 30 $\text{ATR}$ vs. $\text{FMin}$ within-model and cross-modality difference-in-differences contrasts across unadjusted, `adj_age_sex`, and `adj_age_sex_vent` regimes.
3. `camcan_watershed_dataset.csv` — Harmonized dataset with manifest indicators, modality-specific tracts, QC flags, and covariates.
4. `cfa_fi_fit.csv` — Standalone Tier 1 Confirmatory Factor Analysis fit indices for latent Fluid Intelligence ($\chi^2_{\text{scaled}} = 2.522, df = 2, p = 0.2833, \text{CFI}_{\text{robust}} = 0.9993, \text{RMSEA}_{\text{robust}} = 0.0224, \text{SRMR} = 0.0086$).
5. `cohort_demographics.csv` — Age distribution summary ($M = 53.75, \text{SD} = 17.95, \text{median} = 52.90, \text{IQR} = [38.90, 68.80], \text{range} = 18.6\text{--}88.0$) on $N = 513$.
6. `cohort_sex_counts.csv` — Sex breakdown ($253\text{ females }[49.3\%], 260\text{ males }[50.7\%]$).
7. `covariance_matrix_A.csv` — $20 \times 20$ manifest sample covariance matrix for Model A ($\text{FA}$, $N = 513$) enabling standalone `lavaan` reproduction from summary statistics.
8. `covariance_matrix_B.csv` — $20 \times 20$ manifest sample covariance matrix for Model B ($\text{FA}_{\text{tissue}}$, $N = 513$).
9. `covariance_matrix_C.csv` — $20 \times 20$ manifest sample covariance matrix for Model C ($\text{AWF}$, $N = 513$).
10. `covariance_matrix_D.csv` — $20 \times 20$ manifest sample covariance matrix for Model D ($\text{FW}$, $N = 513$).
11. `direct_wm_to_fi_paths.csv` — Direct $\text{WM} \rightarrow \text{FI}$ path coefficients from the $df = 50$ partial-mediation models (`direct`).
12. `directionality_model_comparison.csv` — Fit statistics and $\Delta\text{AIC}$/$\Delta\text{BIC}$ comparing Forward ($df = 60$), Reversed Lower Block ($df = 60$), Partial Mediation ($df = 50$), and Inverted Mediator Ordering ($\text{PS} \rightarrow \text{WM} \rightarrow \text{FI}, df = 56$).
13. `excluded_participants_profile.csv` — Itemized audit of the 34 participants excluded between $N = 547$ and $N = 513$ (4 behavioral outliers, 22 tract outliers [1 overlap], and 9 multi-compartment fitting failures).
14. `excluded_vs_retained_age.csv` — Wilcoxon rank-sum attrition test results comparing retained ($N = 513, M = 53.75\text{ yrs}$) vs. excluded ($n = 34, M = 70.55\text{ yrs}, p = 1.19 \times 10^{-7}$) subgroups.
15. `fi_rsquared_decomposition.csv` — Variance decomposition of latent $\text{FI}$ across `wmonly` ($36.10\%$ Model B; $42.64\%$ Model A), `forward` ($57.77\%$), and `direct` ($62.19\%$ Model B), quantifying the $87.8\%$ mediation share via PS.
16. `indirect_effects_delta_method.csv` — Delta-method total indirect effects ($\text{ind}_k = \sum_{j=1}^6 \beta_{jk}\gamma_j$) and 10-tract Holm-adjusted $p$-values for Models A–D.
17. `means_A.csv` — 20-variable manifest mean vector for Model A ($N = 513$).
18. `means_B.csv` — 20-variable manifest mean vector for Model B ($N = 513$).
19. `means_C.csv` — 20-variable manifest mean vector for Model C ($N = 513$).
20. `means_D.csv` — 20-variable manifest mean vector for Model D ($N = 513$).
21. `mediation_and_equivalence_tests.csv` — Satorra–Bentler scaled nested LRT ($\Delta\chi^2_{\text{scaled}}(10) = 39.853$ in Model B; $45.290$ in Model A) and Markov equivalence verification ($\Delta\ell < 10^{-8}$).
22. `preprocessing_summary.csv` — Step-by-step sample counts across the 4-stage harmonization funnel ($N = 653 \rightarrow 550 \rightarrow 547 \rightarrow 513$).
23. `rsquared_adjusted.csv` — Endogenous $R^2$ values across all endogenous variables in `adj_age_sex` ($R^2_{\text{FI}} = 27.51\%$) and `adj_age_sex_vent` ($R^2_{\text{FI}} = 27.53\%$).
24. `rsquared_unadjusted.csv` — Endogenous $R^2$ values across all endogenous variables in unadjusted Models A–D ($R^2_{\text{FI}} = 57.77\%$).
25. `sensitivity_outlier_regimes_fit.csv` — Global fit metrics across `no_outlier_exclusion` ($N = 538\text{--}547$), `modality_specific_4SD` ($N = 517\text{--}533$), and `common_noexcl` ($N = 538$).
26. `sensitivity_outlier_regimes_paths.csv` — Focal $\text{ATR}$ and $\text{FMin}$ path estimates and 60-test Holm $p$-values across all sensitivity regimes.
27. `standardized_solutions_all_models.csv` — Complete `standardizedSolution()` parameter inventories across all models and covariate regimes.
28. `tract_correlations_A.csv` — $10 \times 10$ inter-tract Pearson correlation matrix $R_A$ for conventional $\text{FA}$ ($N = 513$).
29. `tract_correlations_B.csv` — $10 \times 10$ inter-tract Pearson correlation matrix $R_B$ for $\text{FA}_{\text{tissue}}$ ($N = 513$).
30. `tract_correlations_C.csv` — $10 \times 10$ inter-tract Pearson correlation matrix $R_C$ for $\text{AWF}$ ($N = 513$).
31. `tract_correlations_D.csv` — $10 \times 10$ inter-tract Pearson correlation matrix $R_D$ for $\text{FW}$ ($N = 513$).
32. `tract_to_speed_paths_adjusted.csv` — All 60 upstream $\text{WM} \rightarrow \text{PS}$ standardized paths with 60-test Holm and BH adjusted $p$-values under `adj_age_sex` and `adj_age_sex_vent`.
33. `tract_to_speed_paths_unadjusted.csv` — All 60 upstream $\text{WM} \rightarrow \text{PS}$ standardized paths with 60-test Holm and BH adjusted $p$-values for unadjusted Models A–D.
34. `tract_vif_all_models.csv` — Variance Inflation Factors $\text{VIF}_{mk} = (R_m^{-1})_{kk}$ across all 10 tracts and 4 diffusion modalities ($N = 513$).
35. `unstandardized_solutions_all_models.csv` — Complete `parameterEstimates()` unstandardized solutions with Huber–White robust SEs.
36. `wald_ATR_vs_FMin_adjusted.csv` — Scale-aware Wald equality tests ($\text{SD}_{\text{ATR}}\cdot b_{j,\text{ATR}} = \text{SD}_{\text{FMin}}\cdot b_{j,\text{FMin}}$) under `adj_age_sex` and `adj_age_sex_vent`.
37. `wald_ATR_vs_FMin_unadjusted.csv` — Scale-aware Wald equality tests and 6-outcome Holm adjusted $p$-values for unadjusted Models A and B.
38. `watershed_adjusted_fit.csv` & `watershed_model_comparison.csv` — Complete robust fit indices ($\chi^2_{\text{scaled}}, df, p, \text{CFI}_{\text{robust}}, \text{TLI}_{\text{robust}}, \text{RMSEA}_{\text{robust}} [90\%\text{ CI}], \text{SRMR}, \text{AIC}, \text{BIC}, c_{H_0}/c_{H_1}$) for all primary and covariate-residualised models.
