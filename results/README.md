# Results Directory (`results/`)

This directory stores all tabular statistical outputs (`results/tables/`) generated by `R/watershed_sem_pipeline.R` and all standalone vector figures (`results/figures/`) generated by `scripts/generate_publication_figures.py`.

---

## 1. Tabular Outputs (`results/tables/`)

Running `R/watershed_sem_pipeline.R` exports 28 CSV tables, 1 log file, and 1 session info file. Below is the complete inventory mapped to the corresponding manuscript tables and analyses:
